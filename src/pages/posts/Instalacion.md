# Instalación de Astro

Astro es un framework moderno diseñado para crear sitios web rápidos y optimizados. Antes de comenzar, es necesario tener instalado Node.js en el equipo.

## Requisitos previos

- Node.js 18 o superior.
- Un editor de código, como Visual Studio Code.
- Conexión a internet para descargar dependencias.

## Crear un nuevo proyecto

Para crear un proyecto de Astro, ejecuta el siguiente comando en la terminal:

```bash
npm create astro@latest nombre-proyecto
